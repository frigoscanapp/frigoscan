# FrigoScan — Dispensa, Spesa & Carte (GitHub Pages v4)

Web App PWA pronta per essere pubblicata gratuitamente su **GitHub Pages** (`https://<tuo-utente>.github.io/<nome-repository>/`).

## Novità v4
- **Banner Intelligente "Installa App":**
  - Su **Android (Chrome / Edge / Samsung Internet)** intercetta l'evento di installazione PWA e offre un pulsante diretto **"Installa"** a 1 tocco nell'header e nel banner superiore.
  - Su **iPhone / iPad (Safari)** rileva automaticamente il browser iOS e mostra una guida visiva rapida con i passaggi *Condividi → Aggiungi alla schermata Home*.
  - Scompare automaticamente quando l'app viene avviata come icona installata dalla schermata Home.
